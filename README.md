# ลอยกระทงออนไลน์ มทร.กรุงเทพ (RMUTK Loy Krathong)
## สระน้ำแห่งคำอธิษฐาน มหาวิทยาลัยเทคโนโลยีราชมงคลกรุงเทพ

เว็บแอปพลิเคชันลอยกระทงออนไลน์สำหรับประชาคมมหาวิทยาลัยเทคโนโลยีราชมงคลกรุงเทพ (RMUTK) ทั้งนักศึกษา คณาจารย์ บุคลากร ศิษย์เก่า และบุคคลทั่วไป จำลองบรรยากาศอันเงียบสงบและงดงามของสระน้ำใจกลางมหาวิทยาลัย พร้อมศาลาไทย บันไดเทียบผิวน้ำ สะพานโค้งสีขาว และอาคารเรียนหลังคาแดงอันเป็นเอกลักษณ์

---

### จุดเด่นของผลงาน (Key Features)

1. **สระน้ำจำลองเสมือนจริงแบบเรียลไทม์ (Dynamic Inline SVG Pond Scene)**
   - สลับสภาพแสงและบรรยากาศตามนาฬิกาจริงของอุปกรณ์ผู้ใช้ (05:00-16:59 กลางวัน, 17:00-18:59 พลบค่ำ, 19:00-22:59 แสงจันทร์, 23:00-04:59 ดึกสงัด)
   - เงาสะท้อนของศาลาไทยและแสงประทีปวูบไหวบนระลอกคลื่นน้ำ
   - รองรับการปรับเปลี่ยนมุมมองและเวลาบรรยากาศได้ตามต้องการ
   - ลอยกระทงพร้อมกันได้สูงสุด 30 ใบในตำแหน่งคงที่ พร้อมแอนิเมชันลอยน้ำนุ่มนวลด้วย CSS Transform

2. **ระบบประกอบกระทงอธิษฐาน (Krathong Customizer)**
   - **ฐานกระทง:** ใบตองดั้งเดิม, ขนมปังอบธรรมชาติ, กะลามะพร้าว, และกลีบบัวร่วมสมัย
   - **ดอกไม้บูชา:** ดอกบัวหลวง (ปัญญา/ความสงบ), ดอกดาวเรือง (ความเจริญก้าวหน้า), ดอกกุหลาบ (ความรัก/มิตรภาพ), และดอกบานไม่รู้โรย (ความมั่นคงยั่งยืน)
   - **ประทีปและเทียน:** เทียนทองพร้อมธูปสามดอก, เทียนมินิมอลร่วมสมัย, และเทียนคู่ผูกพัน
   - **โหมดการลอย:** ลอยเดี่ยว (Solo), ลอยคู่ (Couple), และลอยกลุ่ม/สายรหัส (Group)
   - **การจุดประทีป:** แตะที่เปลวเทียนหรือกด Spacebar เพื่อจุดไฟ มีเปลวไฟและควันธูปพวยพุ่ง ต้องจุดเทียนก่อนจึงจะอนุญาตให้ลอยได้

3. **คณะและหน่วยงาน มทร.กรุงเทพ (Editable Faculty Data)**
   - รวบรวม 8 คณะ 1 วิทยาลัย พร้อมกลุ่มศิษย์เก่า บุคลากร และบุคคลทั่วไป:
     1. คณะวิศวกรรมศาสตร์
     2. คณะวิทยาศาสตร์และเทคโนโลยี
     3. คณะบริหารธุรกิจ
     4. คณะศิลปศาสตร์
     5. คณะครุศาสตร์อุตสาหกรรม
     6. คณะเทคโนโลยีคหกรรมศาสตร์
     7. คณะอุตสาหกรรมสิ่งทอ
     8. วิทยาลัยนานาชาติ
     9. ศิษย์เก่า
     10. บุคลากร
     11. บุคคลทั่วไป

4. **หมวดหมู่คำอธิษฐานและข้อความแนะนำ (Wish Categories & Presets)**
   - การเรียนและสอบผ่าน (มิดเทอม ไฟนอล โปรเจกต์จบ เกรดเฉลี่ย)
   - การงานและฝึกงาน (ที่ฝึกงาน สหกิจศึกษา งานประจำ ค้าขาย)
   - ความรักและมิตรภาพ (มิตรภาพกลุ่มเพื่อน คนรัก คนรู้ใจ)
   - สุขภาพและลอยเคราะห์ (ปล่อยวางความเครียด สุขภาพแข็งแรง แคล้วคลาดปลอดภัย)
   - จำกัดความยาวสูงสุด 140 ตัวอักษร พร้อมตัวนับอักขระแบบสด

5. **เซียมซีเสี่ยงทาย มทร.กรุงเทพ (16 Student Fortune Sticks)**
   - 16 คำทำนายภาษาไทยแท้ สำนวนเป็นมิตร ให้กำลังใจ และสะท้อนชีวิตนักศึกษา
   - รองรับทั้งการกดปุ่มเสี่ยงทาย และการเขย่าโทรศัพท์มือถือ (Device Motion Detection โดยขอสิทธิ์อย่างปลอดภัยเมื่อผู้ใช้สัมผัส)

6. **การสร้างการ์ดคำอธิษฐานพร้อมแชร์ (Shareable 1080x1080 PNG Wish Card)**
   - เรนเดอร์การ์ดขนาด 1080x1080 พิกเซล ความละเอียดสูงผ่าน HTML Canvas
   - ลวดลายกรอบไทยประยุกต์สีทอง ชื่อผู้ลอย คณะ คำอธิษฐาน และภาพกระทงจำลอง
   - QR Code เชื่อมต่อตรงสู่กระทงใบนั้น (ด้วย URL parameter `?id=UUID`)
   - ปุ่มดาวน์โหลดภาพ PNG และปุ่มคัดลอกลิงก์

7. **ระบบเชื่อมต่อฐานข้อมูลและ Realtime (Supabase Integration & Demo Mode)**
   - รองรับ Supabase PostgreSQL, RLS Policies, และฟังก์ชัน RPC `increment_bless`
   - Realtime Subscriptions รับฟังกระทงที่เพิ่มใหม่และอัปเดตยอดอธิษฐานทันทีโดยไม่ต้องรีเฟรชหน้าเว็บ
   - **โหมดทดลองอัตโนมัติ (Demo Mode):** หากยังไม่ได้ระบุค่าตัวแปรสภาพแวดล้อม ระบบจะสลับไปใช้ชุดข้อมูลทดลองและบันทึกลง LocalStorage โดยอัตโนมัติ พร้อมแสดงป้าย "โหมดทดลอง" ทุกฟังก์ชันยังคงใช้งานได้สมบูรณ์

8. **ความปลอดภัยและการตรวจสอบข้อมูล (Safety & Rate Limiting)**
   - ตรวจสอบคำหยาบคาย (Profanity Filter) ทั้งภาษาไทยและอังกฤษ
   - จำกัดอัตราการส่ง (Rate Limit / Cooldown 30 วินาที)
   - ป้องกัน XSS โดยเรนเดอร์ข้อความเป็น Plain Text เสมอ (ไม่ใช้ dangerouslySetInnerHTML)
   - รองรับ Accessible WCAG AA, ตัวปรับขนาดตัวอักษร ก/ก+, Touch Target >= 44px และ Prefers-Reduced-Motion

### วิธีการติดตั้งและรันในเครื่อง (Local Setup)

1. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

2. **รันเซิร์ฟเวอร์สำหรับพัฒนา (Development Server):**
   ```bash
   npm run dev
   ```
   เปิดบราวเซอร์ไปที่ `http://localhost:3000`

3. **ตรวจสอบความถูกต้องและการ Build:**
   ```bash
   npm run build
   ```

### การตั้งค่าฐานข้อมูล Supabase (Supabase Setup)

1. สมัครใช้งานหรือเข้าสู่ระบบที่ [Supabase](https://supabase.com)
2. สร้างโปรเจกต์ใหม่ (New Project)
3. ไปที่เมนู **SQL Editor** ในหน้าคอนโซล Supabase
4. คัดลอกเนื้อหาทั้งหมดจากไฟล์ `supabase/schema.sql` วางลงในช่องแก้ไข แล้วกด **Run**
   - สคริปต์จะสร้างตาราง `krathongs`
   - ตารางบันทึกการร่วมอธิษฐาน `krathong_blessings` (ป้องกันการกดซ้ำ)
   - ฟังก์ชัน RPC `increment_bless`
   - นโยบายความปลอดภัยระดับแถว (Row Level Security - RLS)
   - เปิดใช้งาน Supabase Realtime สำหรับตาราง `krathongs`
5. ไปที่เมนู **Project Settings** > **API** เพื่อคัดลอก:
   - `Project URL`
   - `anon public key`
6. สร้างไฟล์ `.env.local` ในโฟลเดอร์โปรเจกต์:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI...
   ```
7. รีสตาร์ทคำสั่ง `npm run dev` ระบบจะเชื่อมต่อกับ Supabase จริงและออกจากโหมดทดลอง

### การอัปโหลดขึ้น GitHub (GitHub Setup)

1. สร้าง Repository ใหม่บน GitHub (เช่น `rmutk-loykrathong`)
2. ดำเนินการ Commit และ Push ในเทอร์มินัล:
   ```bash
   git init
   git add .
   git commit -m "feat: complete RMUTK Loy Krathong web application"
   git branch -M main
   git remote add origin https://github.com/<your-username>/rmutk-loykrathong.git
   git push -u origin main
   ```

### การ Deploy บน Vercel (Vercel Deployment)

1. เข้าสู่ระบบ [Vercel](https://vercel.com) แล้วเลือก **Add New Project**
2. นำเข้า (Import) Repository จาก GitHub ที่เพิ่งสร้าง
3. ในส่วน **Environment Variables** เพิ่มตัวแปร:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   *(หากยังไม่มี Supabase สามารถกด Deploy ก่อนได้ ระบบจะทำงานใน Demo Mode อย่างสมบูรณ์)*
4. กด **Deploy** เพื่อเริ่มการสร้างและเผยแพร่เว็บไซต์
